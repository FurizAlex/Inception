**Description**:

'Inception' aims to broaden your knowledge of system administration by using Docker. In this tutorial You will virtualize several Docker images, creating them in your new personal virtual machine. In this README you will have an inception tutorial to know how the project works.

**Instruction**:

Using the command 'make' will compile the project [COMPILATION MAY TAKE A FEW MINUTES]. Once compiled,
the project should be good to go and you can do *https://alechin.42.fr/* to go to the newly made wordpress
website.

'make re' will rebuild the entire project removing anything in the process.

'make logs' will show the docker logs

'make status' will show all 3 containers info/volumes

'make certs-only' will (re)generate SSL Certificates

'make env' will make an .env file from .env.example

*Docker Desktop may be required if using WSL*
